# 10th-jenkins-ansible-cicd-study

## 작업 규칙

- 모든 작업은 브랜치를 생성해서 진행합니다.
- 브랜치 이름은 반드시 주차/이름 형식으로 작성합니다.
  - 예시: `week2/dongwook`
- 스터디 주차의 내용은 학습 정리 및 공유 목적이므로, main 브랜치로 직접 merge해도 됩니다.
- 실습 주차의 작업은 반드시 Pull Request(PR)를 생성해서 진행합니다.
  - 실습 내용은 PR을 통해 리뷰 후 merge하는 방식으로 관리합니다.
- 작업 시작 전 브랜치를 분기해서 진행하고, 작업 완료 후 브랜치에 반영한 뒤 필요한 경우 PR을 올립니다.

## 머지 정책

- 스터디 주차: main 브랜치로 직접 merge 가능
- 실습 주차: PR 생성 후 검토 및 승인 후 merge
